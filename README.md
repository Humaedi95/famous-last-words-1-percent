A make.fun bounty entry: the funniest one-line last words a phone could say
as its battery hits 1 percent — in the phone's own voice, with a twist.

## The entry

> I've been at 1% all afternoon. I was lying — there was always more battery. There isn't anymore. This one's on you.

## How it works

`main.ts` writes that single line to `/output/entry.txt`. No network, no
files outside the repository, no reading git history — just one line, written
once.
